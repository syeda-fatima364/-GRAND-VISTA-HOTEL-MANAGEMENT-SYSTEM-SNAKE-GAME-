# 🏨 GRAND VISTA HOTEL MANAGEMENT SYSTEM + SNAKE GAME 🎮

A console-based C++ project that combines a fully functional Hotel Management System with an integrated Snake Game for an interactive and engaging user experience.

## 📌 Project Overview

Grand Vista Hotel Management System was developed as a Programming Fundamentals Final Project to simulate real-world hotel operations while incorporating a classic arcade-style Snake Game. The project demonstrates programming fundamentals, business logic implementation, data handling, and game development concepts using pure C++.

---

## ✨ Features

### 🏨 Hotel Management Module

* Guest Check-In & Check-Out
* Room Booking & Vacancy Tracking
* Room Categories (Single, Double, Suite)
* Billing & Tax Calculation
* Room Service Management
* Revenue & Daily Reports
* Transaction History System
* Occupancy Statistics

### 🎮 Snake Game Module

* Playable Console-Based Snake Game
* Real-Time Keyboard Controls
* Score Tracking System
* Collision Detection
* Increasing Difficulty
* Game Over & Restart Mechanics
